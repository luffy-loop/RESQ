# RESQ 5-Minute Demo

## 00:00 — Citizen
Open RESQ. Do not log in.

Click **Report an emergency** and submit a flood/medical rescue request with GPS.

Point out: no account barrier during a crisis.

## 01:00 — Authority
Open `/login` as an authority.

Activate **Hyderabad Flood Response** and show the command center.

Point out the live incident banner, emergency queue, responder readiness, shelters, supplies and map.

## 02:00 — Volunteer
Open `/login` as a volunteer.

Show:
- Available/paused state
- Open response queue
- Assigned emergencies
- Start response
- Resolve
- GPS sharing

## 03:00 — NGO
Open `/login` as an NGO.

Register water/medical/food resources and commit a resource to an open need.

## 04:00 — Live coordination
Return to the command center.

Show the emergency status changing and volunteer GPS appearing on the map.

## 05:00 — Citizen tracking
Open `/track` with the private report token.

Show Assigned → Responding → Resolved.

Close with the message:

**One live network for people, responders, shelters and resources.**
